# Star Blaster

素の HTML / CSS / JavaScript で作った縦スクロールシューティングゲームです。ビルド不要で、`index.html` をブラウザで開くだけで遊べます。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 画面をドラッグ |
| ショット | スペース / Z | ドラッグ中は自動連射 |
| ボム | X / B | 右下の BOMB ボタン |
| 一時停止 | P | タップで再開 |
| スタート / リトライ | Enter | タップ |

- 敵は3種類: 赤(直進)・橙(ジグザグ)・紫(停止して3way弾を撃つ)
- ひし形の武器アイテムを取ると武器チェンジ。同じ武器を取るとレベルアップ(最大3)。やられるとレベルが1下がります

| 武器 | アイテム | 特徴 |
| --- | --- | --- |
| VULCAN | V (黄) | まっすぐ飛ぶ連射弾。レベルで本数が増える |
| SPREAD | S (橙) | 扇状に広がる弾。3 / 5 / 7 方向 |
| LASER | L (水色) | 敵を貫通するビーム。レベルで威力アップ |
| HOMING | H (紫) | 敵を追いかけるミサイル。2 / 3 / 4 発 |
| WAVE | W (緑) | 左右にうねりながら進む大きめの弾 |

- **ボム**: 画面内の敵全員に大ダメージを与え、敵弾をすべて消します。使うと少しの間無敵。初期3発(最大5発)、赤い **B** アイテムで1発追加、やられると3発まで補充
- 時間経過で難易度が上がります。ハイスコアはブラウザに保存されます

## ローカルで起動

```sh
# そのまま開く
open index.html
# または簡易サーバー
python3 -m http.server 8000   # → http://localhost:8000
```

## ファイル構成

- `index.html` — ページ本体
- `style.css` — 画面サイズに合わせたキャンバス表示
- `game.js` — ゲームロジック(入力・敵・当たり判定・描画・メインループ)
